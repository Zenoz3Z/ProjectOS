# Private prepared summaries

Generated cache files and their evidence excerpts are excluded from Git. Only this README is allow-listed.

The researcher creates these caches with `study_project_manager.py prepare`. The tutorial cache is shared. Participant caches have separate participant-code and project-ID namespaces. Review corrections and participant notes belong in review storage and are not written to these caches.

Source, model, prompt/schema or retrieval-pipeline changes invalidate the cache. Prepare again before a study session; do not reprepare a project while a participant is reviewing it. These files can contain participant project material and must follow the same agreed storage, access and deletion arrangements as the source pack.
