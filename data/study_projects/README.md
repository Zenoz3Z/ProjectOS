# Local study project packs

Participant project directories belong here and are excluded from Git. This README is the only allow-listed file in this directory. Do not put project content in it.

Use a validated participant code such as `P01` as the project folder name. Copy the empty four-category template from `config/study_project_template/`, then add only the approved, non-sensitive project materials. Missing categories are allowed; do not invent records to fill them.

See the [project-pack guide](../../project_knowledge/feedback/user_testing/iteration_1/participant_project_pack_guide.md) and [draft data protocol](../../project_knowledge/feedback/user_testing/iteration_1/participant_owned_project_data_protocol_draft.md) before preparing a real participant pack. Formal use requires supervisor/ethics confirmation.
