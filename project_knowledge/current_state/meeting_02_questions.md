### 2. Evaluation material

**Question to ask:**

For participant evaluation, should I use one prepared project archive, participants’ own project archives, or a combination of both?

**My current recommendation:**

Use one prepared archive as the primary task so that all participants encounter the same project states and retrieval problems.

Use participants’ own projects only as an optional discussion or secondary activity.

**Why I need this decision:**

Using personal projects may provide stronger real-world relevance, but it would reduce comparability and may create privacy or setup problems.

**Possible outcomes:**

- [ ] Prepared archive only
- [ ] Personal project archives only
- [ ] Prepared archive plus optional personal-project discussion
- [ ] Different approach

**Supervisor response:**

To be completed during the meeting.

**Action after meeting:**

To be completed during the meeting.

### 3. Evaluation design

**Question to ask:**

Is a small task-based qualitative study appropriate, or does the project need a formal comparison with a conventional folder-review or AI-summary workflow?

**My current recommendation:**

Use a formative qualitative study because the sample will be small and the research focuses on evidence inspection, correction and reflective judgement.

Avoid making strong performance claims from an underpowered comparison.

**Why I need this decision:**

A comparison study would require additional archives, counterbalancing and more participant time.

**Possible outcomes:**

- [ ] Qualitative task-based study
- [ ] Comparison with folder review
- [ ] Comparison with generic AI summary
- [ ] Mixed approach
- [ ] Different approach

**Supervisor response:**

To be completed during the meeting.
