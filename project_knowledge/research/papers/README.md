# Research paper storage

This directory is reserved for locally downloaded research papers. PDF files are excluded from Git and are not part of the demonstration archive indexed by ProjectOS.

The repository includes [literature notes](../literature%20notes/) with source references. Consult the original publishers or authors for the papers and their access and reuse terms; the ProjectOS code licence does not apply to third-party publications.

The earlier `research/` tree is retained as part of the development history. Existing local papers and research records have not been deleted.
